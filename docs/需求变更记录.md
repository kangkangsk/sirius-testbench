## 修改内容摘要

新增一个独立 Node + Vue 应用，用于:

- 设置本地文件工作空间。
- 通过有界面 Chromium 抓取网站 HTTP 请求。
- 将业务 HTTP 请求和 JS/CSS/图片/HTML 等静态资源分开保存和展示。
- 原样保存 Cookie、Session、Header、Body。
- 抓包后删除或禁用不需要回放的接口。
- 保存统一登录态覆盖配置。
- 支持回放时替换目标 IP/域名和端口。
- 支持标记登录接口后把登录响应 Cookie 接续到后续请求。
- 执行整理后的请求回放测试。
- 导出 curl 回放脚本。

## 接口变更

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/workspace` | 获取工作空间摘要 |
| POST | `/api/workspace` | 设置工作空间目录 |
| GET | `/api/sessions` | 查询抓包会话 |
| GET | `/api/sessions/:sessionId` | 查询会话详情和请求列表 |
| POST | `/api/capture/start` | 启动有界面 Chromium 抓包 |
| POST | `/api/capture/:sessionId/stop` | 停止抓包并写 HAR |
| PATCH | `/api/sessions/:sessionId/requests/:requestId` | 修改请求启用状态或分类 |
| DELETE | `/api/sessions/:sessionId/requests/:requestId` | 删除请求 |
| POST | `/api/sessions/:sessionId/auth-override` | 保存登录态覆盖配置 |
| POST | `/api/sessions/:sessionId/replay` | 回放 enabled 请求 |
| POST | `/api/sessions/:sessionId/scripts/curl` | 生成 curl 脚本 |

## 建议测试用例

1. 设置工作空间后刷新页面，确认目录和会话统计可读取。
2. 输入目标 URL 开始抓包，确认弹出有界面 Chromium。
3. 登录目标网站并操作查询，确认请求列表实时增加。
4. 停止抓包，确认 `capture.har`、`requests.json`、`resources.json` 写入。
5. 在请求整理页禁用 POST/PUT/PATCH/DELETE，确认回放只执行启用请求。
6. 保存统一 Cookie/Header 后用“统一替换”模式回放。
7. 生成 curl 脚本并检查文件路径。
